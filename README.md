## 三个藏在条款里的限制

这几条写在服务条款和知识库里，多数低价 VPS 的推荐文章不会提，但直接影响使用：

1. **嵌套虚拟化默认禁止**。在 KVM VPS 里再跑虚拟机、hypervisor、需要硬件虚拟化的模拟器，未经书面批准不允许，而且官方不保证暴露 Intel VT-x（vmx）或 AMD-V（svm）标志。想在 VPS 里再开虚拟机的需求直接没戏，那是独立服务器的事。Docker、Docker Compose、LXC/LXD、Kubernetes、K3s 这类容器化负载不受限制，正常用。
2. **挖矿和群发邮件明令禁止**。加密货币挖矿（含 CPU mining）、邮件群发、暴力破解、向外 DDoS、Traffic Exchange 都在禁止列表里，违规可能直接终止服务。
3. **默认无托管、无备份**。VPS 默认是无管理服务，也不含托管备份，官方明确不对数据完整性负责，条款里强烈建议用户自己维护网络外的备份。数据丢了自己扛，重要东西定时备份到机器外面。

流量超了倒不用太紧张：超限后限速到 10Mbps，不停机、不额外扣费。另外 VPS 客户在一定时间内申请更换 IP 可以免费处理一次，具体时限以知识库说明为准。

- **Vultr**：按小时计费，随时创建销毁，适合短期测试和学习场景，没有沉没成本。但同样的钱在 RackNerd 能拿到年付的长期机器，跑长期服务 Vultr 算下来贵不少。

一句话概括：线路优先选搬瓦工或 HostDare，灵活测试选 Vultr，比配置和价格选 RackNerd。
